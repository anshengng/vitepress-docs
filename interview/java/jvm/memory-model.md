# JVM 运行时内存区域

## 题目

> JVM 内存分为哪几个区域？哪些线程私有、哪些共享？各区域溢出异常是什么？

## 核心要点

```
线程私有                        共享
├─ 虚拟机栈（栈帧：局部变量表等）   ├─ 堆（对象实例，GC 主战场）
├─ 本地方法栈                     ├─ 方法区/元空间（类信息、常量，1.8 起用本地内存）
└─ 程序计数器（PC 行号）           └─ 运行时常量池
```

- **栈**：`StackOverflowError`（递归过深）
- **堆**：`OutOfMemoryError: Java heap space`
- **元空间**：`OutOfMemoryError: Metaspace`（动态生成类过多，如 CGLIB 滥用）
- 逃逸分析：不逃逸的对象可栈上分配/标量替换，减少 GC 压力
