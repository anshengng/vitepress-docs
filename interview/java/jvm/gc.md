# GC 算法与收集器

## 题目

> 如何判断对象已死亡？常见 GC 算法和收集器有哪些？G1 的特点？

## 核心要点

### 存活判定

- 引用计数（有循环引用问题，Java 不采用）→ **可达性分析**（GC Roots：栈引用、静态变量、常量）

### 三种基础算法

| 算法 | 特点 |
| --- | --- |
| 标记-清除 | 碎片 |
| 标记-复制 | 年轻代用，浪费空间但无碎片 |
| 标记-整理 | 老年代用，无碎片但移动成本高 |

### 收集器演进

- Serial → ParNew → Parallel Scavenge → **CMS**（并发标记清除，碎片+并发失败）→ **G1**（Region 化、可预测停顿、Mixed GC）→ ZGC（<10ms 停顿）
- 分代：年轻代 Minor GC 频繁，对象经年龄阈值（默认 15）晋升老年代
- 大对象直接进老年代；Full GC 要排查（System.gc、元空间不足、晋升失败）
