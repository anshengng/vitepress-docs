# 限流、熔断与降级

## 题目

> 常用限流算法有哪些？熔断和降级有什么区别？Sentinel/Hystrix 的实现思路？

## 核心要点

### 限流算法

- **固定窗口计数**：临界突刺问题
- **滑动窗口**：均摊到小格，解决临界问题（Sentinel 默认）
- **漏桶**：恒定速率流出，削峰
- **令牌桶**：允许突发（Guava RateLimiter）
- 分布式限流：Redis + Lua（原子取令牌）或网关层统一限流

### 熔断 vs 降级

- **熔断**：下游异常率/慢调用超阈值 → 快速失败，半开状态试探恢复（断路器三态：Closed→Open→Half-Open）
- **降级**：主动放弃非核心功能保核心（返回兜底数据、缓存旧值）
- 隔离手段：线程池/信号量隔离，防止单接口拖垮全局
