# 事务隔离级别与 MVCC

## 题目

> MySQL 的隔离级别分别解决什么问题？MVCC 的实现原理？

## 核心要点

### 隔离级别

| 级别 | 脏读 | 不可重复读 | 幻读 |
| --- | --- | --- | --- |
| 读未提交 | ✓ | ✓ | ✓ |
| 读已提交 | ✗ | ✓ | ✓ |
| **可重复读（默认）** | ✗ | ✗ | 基本解决* |
| 串行化 | ✗ | ✗ | ✗ |

\* RR 下快照读靠 MVCC，当前读靠 Next-Key Lock（间隙锁）防幻读

### MVCC 三件套

- 每行隐藏列：`trx_id`（事务 id）、`roll_pointer`
- **undo log 版本链**：修改记录旧版本串成链
- **ReadView**：快照读时生成（RC 每次查询生成、RR 首次生成），按 `creator_trx_id / min_trx_id / max_trx_id / m_ids` 判断版本链上哪个可见
