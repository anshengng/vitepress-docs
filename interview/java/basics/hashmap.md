# HashMap 底层原理

## 题目

> HashMap 的底层结构是什么？put 流程、扩容机制？JDK 1.7 与 1.8 的区别？

## 核心要点

### 结构（JDK 1.8）

- 数组 + 链表 + 红黑树
- 链表长度 ≥ 8 且数组长度 ≥ 64 → 转红黑树；≤ 6 → 退化回链表

### put 流程

```
key 计算 hash（高16位异或低16位，扰动函数）
  → (n-1) & hash 定位桶下标
  → 桶为空？直接放入
  → 冲突？链表尾插 / 树插入
  → size > threshold？扩容为 2 倍
```

### 关键结论

- 默认容量 16、负载因子 0.75，容量始终为 2 的幂（扩容时元素要么原位、要么原位+旧容量）
- 1.7 头插法多线程扩容会成环 → 1.8 尾插法，但依然**线程不安全**（并发丢数据）
- 线程安全替代：ConcurrentHashMap（CAS + synchronized 锁桶头）
