# data 为什么是一个函数

## 为什么需要

组件是**可复用的构造器**：同一个组件可能被实例化 N 次。如果 data 直接写对象，这个对象会被所有实例共享——一个实例改数据，其他实例跟着变，状态互相污染且极难排查。面试考察点：是否理解"组件复用 = 多次实例化"，以及函数每次调用返回**新对象**这一隔离机制；顺带能引出"为什么根组件的 data 可以是对象""Vue3 setup 为什么直接 return 对象"等延伸。

## 核心要点

### 1. 组件复用与实例隔离（ASCII 图解）

```
❌ 假设 data 直接是对象（所有实例共享同一份引用）：

        data = { count: 0 }          ← 组件定义时创建，只有一份
              ▲       ▲       ▲
              │       │       │
          实例A     实例B     实例C     ← 三个 <Counter/> 指向【同一个】对象

   用户点击实例A → A.count = 1
   内存里唯一的 count 变成 1 → B、C 的视图也跟着显示 1   ← 状态串了！

✅ data 是函数（每个实例调用一次，各得新对象）：

   实例A ──调用──► data() ──► return { count: 0 }   ← 新对象① (地址 0x1a)
   实例B ──调用──► data() ──► return { count: 0 }   ← 新对象② (地址 0x2b)
   实例C ──调用──► data() ──► return { count: 0 }   ← 新对象③ (地址 0x3c)

   改 A 的 count → 只动对象①，B、C 互不影响 ✅
```

```javascript
// 组件复用的典型场景：一个计数器用在三个地方
export default {
  data() {
    return { count: 0 }   // 每次调用 return 一个【全新对象】
  }
}
```

本质：Vue 内部 `new Vue(options)` 初始化每个组件实例时执行 `vm.$data = options.data.call(vm)`——**函数每次执行都产生新的对象字面量**，天然实现实例级隔离；对象字面量只在定义组件时创建一次，共享引用必然串状态。

### 2. 为什么根实例（new Vue / createApp）的 data 可以是对象

```
根组件一个页面【只有一个实例】，不存在"多实例共享"问题
  → 直接传对象不会污染别人，Vue 允许 data: { ... } 简写
组件会被复用 N 次 → 必须函数，强制每次返回新副本
```

### 3. Vue3 setup 为什么直接 return 对象（延伸加分）

```javascript
// setup 是"每个实例各执行一次"的函数
// return 的对象字面量在每次 setup 调用时重新创建 → 天然隔离
export default {
  setup() {
    const count = ref(0)   // ref 也是在 setup 内新建的
    return { count }        // 不需要再包一层函数
  }
}
```

对比记忆：Options API 的 data 在**组件定义阶段**求值（所以必须是函数推迟到实例化），setup 本身就在**实例化阶段**执行（所以直接返回对象即可）。

## 面试答法

### 30 秒版本（可直接背诵）

> 组件是可复用的，同一个组件会被实例化多次。如果 data 直接写成对象，这个对象在组件定义时只创建一次，所有实例共享同一个引用——一个实例改了 count，其他所有实例的视图都跟着变，状态互相污染。把 data 写成函数后，Vue 在初始化每个实例时调用它，每次调用都 return 一个全新的对象，各实例持有独立副本，互不干扰。根组件一个页面只有一个实例，不存在共享问题，所以 new Vue 时 data 允许直接传对象。Vue3 的 setup 本身就是每实例执行一次的函数，return 的对象天然是新副本，所以不需要再包函数。

### 深入展开

1. **先画共享图**：三个实例 ▲ 指向同一个 data 对象 → 改一处全变，点出"引用类型共享"是根因
2. **再画隔离图**：data() 每次 return 新对象，三个不同内存地址，互不影响
3. **讲 Vue 内部机制**：实例化时 `data.call(vm)` 执行函数取返回值作为 $data，再递归响应式化
4. **对比根实例**：单实例无共享问题，所以允许对象简写——反证"函数"是为复用服务的
5. **延伸到 Vue3**：setup 执行时机就是实例化，return 对象已隔离；组合式 API 的 ref/reactive 同理都是"调用内新建"

### 常见追问

- **根组件 data 为什么可以是对象？** → 一个应用根实例只有一个，不存在多实例共享同一引用的问题
- **data 函数返回的对象里嵌套引用类型，还串吗？** → 不会跨实例串：每个实例的嵌套对象也是各自 return 时新建的字面量；但如果 data 里引用了**外部**定义的共享对象（模块级 const obj），那还是会串——隔离的是"每次新建"，不是"深拷贝"
- **Vue3 setup 里 return 对象为什么不用函数？** → setup 每个实例各执行一次，return 的对象字面量每次都是新建的，等价于 data 函数的效果
- **methods 为什么不用写成返回新对象的函数？** → methods 是行为不是状态，共享同一份函数定义没有副作用问题；状态才需要实例级副本
- **如果组件里定义 `data: {x:1}`（对象）会怎样？** → Vue 开发环境直接警告报错"Component data function is missing"，强制函数形式
